# slimrate-site

## Общие правила SlimRate

Перед началом любой задачи обязательно прочитай [общие правила SlimRate](https://github.com/SlimRate/slimrate-documentation/blob/main/workspace/AGENTS.md) и указанные там инструкции по разработке и проверкам. Они действуют для этого репозитория, в том числе при работе вне SlimrateFeaturesDev.

Локальные инструкции дополняют общие правила. При противоречии по порядку PR, review, merge и выпуска действуют общие правила; прямые указания пользователя имеют приоритет. Если источник недоступен, сообщи об этом и не считай общие правила прочитанными.
